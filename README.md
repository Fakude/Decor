# Dawn Park Catering & Decor

[![Validate and deploy site](https://github.com/Fakude/Decor/actions/workflows/pages.yml/badge.svg)](https://github.com/Fakude/Decor/actions/workflows/pages.yml)

A responsive brochure website for a catering and decor service. The project focuses on service discovery, event imagery and clear contact paths for prospective clients.

## Run locally

Open `index.html` in a modern browser. The site is framework-free and has no build step.

## Deployment

GitHub Actions validates the JavaScript on every push and pull request. A successful push to `main` is deployed through GitHub Pages.

## Project structure

- `index.html` — content and page structure
- `Photoslider.css` — responsive styles
- `Photoslider.js` — gallery and UI behaviour
- `Gallery/` — project images
- `.github/workflows/pages.yml` — automated validation and deployment

## Portfolio evidence

Demonstrates responsive front-end development, asset organisation, client-facing information design and CI/CD with GitHub Actions.
